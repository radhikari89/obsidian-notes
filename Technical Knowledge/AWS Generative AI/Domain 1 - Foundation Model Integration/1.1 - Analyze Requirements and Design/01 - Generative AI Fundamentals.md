# Generative AI Fundamentals
Generative AI produces new content (text, code, images or audio) from learned patterns. A foundation model (FM) is a broadly pretrained model adaptable to multiple tasks.

| Concept | Meaning |
|---|---|
| Token | Unit of model input/output |
| Context window | Capacity for input and generated context |
| Embedding | Numeric representation useful for similarity search |
| Inference | Running a trained model to generate output |
| Hallucination | Plausible but unsupported or incorrect output |

## Developer responsibilities
Translate business needs into architecture, integrate models, evaluate quality, manage data access, implement safeguards and operate the system.

> [!question] Recall
> Why is a foundation model not a complete application? It needs integration, data, security, evaluation and operational controls.
