# AWS Well-Architected Framework
| Pillar | GenAI application example |
|---|---|
| Operational excellence | Runbooks, evaluation automation, versioning |
| Security | Least privilege, sensitive data protection, threat modeling |
| Reliability | Rate-limit handling, recovery, fallback |
| Performance efficiency | Model sizing, latency and throughput testing |
| Cost optimization | Token budgets and cost per successful task |
| Sustainability | Avoid unnecessary inference and oversized models |

The Well-Architected Tool supports structured architecture reviews. The Generative AI Lens adds workload-specific guidance; neither automatically certifies a system as compliant.

## Review approach
Record the workload, evaluate risks, prioritize remediation, assign owners and repeat reviews as architecture evolves.
